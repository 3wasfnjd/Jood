# جود — رعب الحارة

لعبة Roblox تعاونية (1–4 لاعبين) من **عبودين قيمز**.
الحارة مظلمة و"جود" مجنونة الحارة تتجول فيها. الفريق يدوّر الفيوزات في الدكاكين، يشغّل أعمدة الإنارة الستة، ثم يشعل الفانوس الكبير في الساحة ويدافع عنه لين تنطرد جود.

## طريقة اللعب
- **الفيوزات:** في الدكاكين المفتوحة. كل لاعب يشيل فيوز واحد.
- **الأعمدة:** ركّب الفيوز (4 ثواني). عمودا الوسط الشمالي والجنوبي يحتاجون لاعبَين يسحبون المفتاحين مع بعض.
- **الضوء يحميك:** جود ما تدخل تحت عمود شغال. الكشاف (زر F أو زر "كشاف" بالجوال) يبطّئها إذا وجّهته عليها، والبطارية تشحن تحت الأعمدة.
- **جود تطفي الأعمدة:** العمود يرمش ثم يخرب، وتصلحه بالضغط المطوّل.
- **الطيحة:** إذا مسكتك جود تطيح، وصاحبك عنده 30 ثانية ينقذك.
- **النهاية:** أشعلوا الفانوس وخلّوا 5 أعمدة على الأقل شغالة لمدة دقيقة.

## هيكل المشروع (Rojo)
| الملف | الدور |
|---|---|
| `src/shared/Config.luau` | كل الأرقام القابلة للضبط |
| `src/server/MapBuilder.luau` | يبني الحارة بالكود |
| `src/server/Lamp.luau` | أعمدة الإنارة وحالاتها |
| `src/server/Jood.luau` | شخصية جود وذكاؤها |
| `src/server/Main.server.luau` | دورة الجولة |
| `src/client/Hud.client.luau` | واجهة اللاعب وزر الكشاف |

## البناء والنشر (GitHub Actions)
كل push يبني `Jood.rbxlx` ويرفعه كـ artifact.
النشر لـ Roblox يشتغل تلقائياً على فرع `main` لما تضيف هالأسرار في الريبو:
- `ROBLOX_API_KEY` — مفتاح Open Cloud بصلاحية Place Publishing لهذي اللعبة
- `ROBLOX_UNIVERSE_ID` — رقم اللعبة (Experience)
- `ROBLOX_PLACE_ID` — رقم المكان (Place)
