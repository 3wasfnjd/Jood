# جود — مجنونة الحارة

لعبة رعب تعاونية في Roblox من **عبودين قيمز**: حارة سعودية بالليل، فيها استراحة عبدالله، وجود تطارد اللاعبين.

## طريقة اللعب
ثلاث قطع كهرباء ← المولد ← مفتاح بيت جود ← بوابة الهروب.
- **التخبي:** دواليب تحميك لوقت محدود. الساحة الزرقاء آمنة.
- **الحبل 🪢:** يظهر في مكان عشوائي. اللي ياخذه يقرّب من جود ويضغط **Q** (أو زر «اربط» بالجوال)، فتنربط 8 ثواني. بعدها تتحرر معصّبة وتدوّر عليكم. الحبل الجاي يظهر في مكان ثاني.
- **الحلاوة 🍬:** متوزعة بالحارة، وتعبّي طاقة الركض.
- **الاستراحة:** نطّاطات، وبالونات، وزينة إنارة.
- **اللوحات:** لوحات بيوت بأسماء عوائل، ومحلات قديمة، ولوحات طرق زرقاء.

التحكم: WASD، Shift ركض، F كشاف، E تفاعل وخروج من المخبأ، Q الحبل.

## هيكل المشروع
| المسار | المحتوى |
|---|---|
| `base/Joud-Hara.rbxlx` | الماب (المباني والمجسّمات المضمّنة). يتعدّل في Studio. |
| `src/shared/*.luau` | ReplicatedStorage › HaraShared (الإعدادات، القواعد، الحبل، اللوحات، الأشياء الفريحية…) |
| `src/server/HaraServer.server.luau` | منطق الخادم: الجولة، جود، الحبل، الحلاوة |
| `src/client/HaraClient.client.luau` | الواجهة والتحكم والنطّاطات |
| `assets/` | ملفات المصدر: مجسّم جود (GLB) والاستراحة (Blender) |
| `tools/build_place.py` | يدمج سكربتات src في الماب ← `Jood.rbxlx` |
| `tools/lighten_joud.py` | يصغّر خامة جود المضمّنة (استُخدم مرة: 1024 ← 512) |

## تعديل الماب في Studio
عدّل وحفظ الملف، وأرسله ليُستبدل به `base/Joud-Hara.rbxlx`. السكربتات تبقى من `src`.

## البناء
كل push يبني `Jood.rbxlx` ويحدّث رابط التحميل:
https://github.com/3wasfnjd/Jood/releases/download/latest/Jood.rbxlx

في Studio: Experience Settings › Security › فعّل **Allow Mesh / Image APIs** حتى يظهر شكل جود والاستراحة المفصّل. بدونه اللعبة تشتغل بالشكل المبسّط.
